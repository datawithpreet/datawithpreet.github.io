06 · Retail · Equipment Maintenance · Agentic AI

Every Minute a Coffee Machine Is Down Is a Missed Sales Opportunity.

When revenue-generating equipment fails, technicians need answers — not hundreds of pages of manuals. FixMate AI helps them identify equipment issues, find the right troubleshooting steps, recognize parts from images, and resolve problems faster using internal documentation and relevant external sources.

Real-world proof: 7-Eleven built a Technician's Maintenance Assistant with Databricks that cuts documentation search time from minutes or even hours to seconds and improves first-time-fix rates — adopted by more than 1,000 technicians.
Databricks: How 7-Eleven Transformed Maintenance Technician Knowledge Access ↗ · Watch the Databricks Summit session ↗

The business outcome

It's 7 a.m. at a convenience store. The coffee machine is down, the display says Error E17, and customers are arriving. Today, the manager flips through a binder, calls a district supervisor, and loses the morning coffee rush. The outcome this project delivers: instant, cited, safety-gated maintenance answers — the right troubleshooting steps from the actual manual, the current version, with parts identified and technician-only procedures locked down.

Equipment downtime is lost revenue, but the bigger cost is unsafe fixes. FixMate's core principle — enforced in code, visible in output — is: internal documents FIRST, web SECOND. Never invent a maintenance procedure to fill a documentation gap.

How the agent works

Plan → tool → observe trace, rendered in the web UI with highlighted plans, tool calls, and safety gates:

1
Diagnose

Takes the symptom (error code, description, or simulated photo metadata) and identifies the equipment model and likely issue class.

2
Internal search first

Searches internal manuals, error-code tables, and parts catalogs. If the answer is supported: validate and guide with a citation to the manual and version.

3
Prove the gap

If internal search finds nothing, the agent must prove the search was conclusive (right model? right doc version? fully indexed?) before looking anywhere else.

4
External, labeled

Falls back to approved external sources (manufacturer docs first); external guidance is explicitly labeled EXTERNAL, never presented as approved procedure.

5
Safety gate

Some procedures are technician-only, full stop. The agent refuses to walk an untrained employee through hazardous repairs and escalates instead.

6
Close the loop

Recurring documentation gaps are flagged for the documentation team; an expert publishes a manual update, the new version is indexed, and the same question now resolves internally.

Data engineering

The demo runs on a synthetic equipment corpus for the fictional BrewPoint Retail chain (every machine, manual, error code, part, store, and person is synthetic): error-code tables, troubleshooting workflows, parts catalogs with simulated part-detection metadata, and manual versions. The retrieval flow mirrors the real 7-Eleven architecture pattern — identify the equipment, search internal documents first, fall back to external sources — scaled down to exact-match lookup over dicts, stdlib-only, fully offline.

Architecture

LayerWhat it does
DiagnosisMaps symptoms, error codes, and simulated photo metadata to equipment model and issue class.
Internal retrievalManuals, error codes, parts catalogs — first and preferred source, with citations.
Gap proverVerifies a "not found" is conclusive before any external lookup is allowed.
External retrievalApproved manufacturer sources; always labeled EXTERNAL, never as approved procedure.
Safety gateTechnician-only procedures are hard-blocked for untrained users; honest escalation on uncertainty.
Feedback loopRecurring gaps → documentation team → manual update → re-indexed corpus.
Web UIapp.py over stdlib http.server; byte-identical output.

Implementation

  • Deterministic: stdlib only, offline, no API keys — identical runs; TEST-LOG.md and TEST-LOG-EDGE.md record determinism and adversarial edge cases (never invents a procedure, never crashes).
  • Honest boundaries: when the manual lacks the answer, the agent says so and escalates instead of inventing a procedure.
  • Real-world anchor: the demo is built around the real 7-Eleven use case demonstrated at Databricks Summit; it illustrates the approach rather than claiming to be 7-Eleven's production system.

Technical details

  • Run it: python3 app.py, then open http://localhost:8006 in Chrome and click Run live demo (binds 127.0.0.1, port 8006).
  • Repo: ynpreet/fixmate-ai ↗
  • Success criteria: internal-first resolution with citations; safety gate blocks technician-only procedures; honest escalation on gaps; identical output across runs.
